**StillCord 3.3 · Restless Expanded**, packaged for **BetterDiscord**.

- One plugin file with the theme built in.
- Floating Browse, connected role-accented bubbles, reading mode, and smooth wheel motion.
- Minimal settings with ZIP-based weather/time, inbox and optional Windows media.
- **15 new effects** join the original ten: 25 individual switches in four tidy groups.
- Six redesigned live wallpapers: Silk, Orbit, Aurora, Eclipse, Prism, and Contour.
- Subtle, Expressive, and All out presets, with two light colors and extra lighting controls.
- Automatic pause when hidden, unfocused, or fullscreen, optional system reduced motion, and clean disable/re-enable behavior.
- Efficient rendering is the default: one moving artwork group, static ambient reflections, and a ten-effect limit. Subtle uses still artwork.
- Restored the chat panel’s rounded lower edge and balanced its bottom glass lighting.
- Shared visual source with the Vencord edition.

Download **StillCord.plugin.js** for the addon alone, or **StillCord-BetterDiscord-3.3.0.zip** for the addon and optional media helper.

[Install instructions](https://github.com/ll2Rawll/StillCord/blob/main/docs/BetterDiscord.md) · [Six actual Discord previews](https://github.com/ll2Rawll/StillCord#six-ways-to-make-it-yours)

Validation: JavaScript checks, 22 unit/integration-boundary tests, browser layout/settings and motion lifecycle checks, and the actual Discord desktop app. Restless is off by default; enable it in **StillCord settings → Restless**. This is the BetterDiscord edition; use the separate Vencord release for Vencord.
