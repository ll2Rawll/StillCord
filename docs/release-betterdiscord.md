**StillCord 3.2 · Restless**, packaged for **BetterDiscord**.

- One plugin file with the theme built in.
- Floating Browse, connected role-accented bubbles, reading mode, and smooth wheel motion.
- Minimal settings with ZIP-based weather/time, inbox and optional Windows media.
- New **Restless** settings tab with ten individually adjustable visual effects.
- Original Silk, Orbit, and Aurora live backgrounds, with color, intensity, and pace controls.
- Automatic pause when hidden or fullscreen, optional system reduced motion, and clean disable/re-enable behavior.
- Shared visual source with the Vencord edition.

Download **StillCord.plugin.js** for the addon alone, or **StillCord-BetterDiscord-3.2.0.zip** for the addon and optional media helper.

[Install instructions](https://github.com/ll2Rawll/StillCord/blob/main/docs/BetterDiscord.md) · [Six actual Discord previews](https://github.com/ll2Rawll/StillCord#six-ways-to-make-it-yours)

Validation: JavaScript checks, 19 unit/integration-boundary tests, browser layout/settings and motion lifecycle checks, and the actual Discord desktop app. Restless is off by default; enable it in **StillCord settings → Restless**. This is the BetterDiscord edition; use the separate Vencord release for Vencord.
