StillCord's integrated glass theme and workspace, packaged for **BetterDiscord**.

- One plugin file with the theme built in.
- Floating Browse, connected role-accented bubbles, reading mode, and smooth wheel motion.
- Minimal settings with ZIP-based weather/time, inbox and optional Windows media.
- Shared visual source with the new Vencord edition.

Download **StillCord.plugin.js** for the addon alone, or **StillCord-BetterDiscord-3.1.0.zip** for the addon and optional media helper.

[Install instructions](https://github.com/ll2Rawll/StillCord/blob/main/docs/BetterDiscord.md) · [Six actual Discord previews](https://github.com/ll2Rawll/StillCord#six-ways-to-make-it-yours)

Validation: JavaScript checks, 13 unit/integration-boundary tests, and browser layout/settings regression checks. This is the BetterDiscord edition; use the separate Vencord release for Vencord.
