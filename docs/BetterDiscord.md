# StillCord · BetterDiscord

1. Install BetterDiscord from https://betterdiscord.app/.
2. Copy `StillCord.plugin.js` into **User Settings → BetterDiscord → Plugins → Open Plugins Folder**.
3. Enable **StillCord**. Its theme is built in; no separate theme is needed.
4. Open **Browse → ⋯ → StillCord settings**, or the plugin card's settings button.
5. Set a five-digit US ZIP in **Widgets & location** for local weather and time.

The optional Windows media adapter is installed with `media/Install-Media.ps1`
and requires Node.js. It supports both StillCord editions and recognizes the
older StillSpeed setup. It is only needed for Windows-wide media controls.

Use the Vencord release instead if you use Vencord. Do not load both client mods
in the same Discord installation.

Previews, documentation and source: https://github.com/ll2Rawll/StillCord
